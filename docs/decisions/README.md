# Architecture Decision Records

Each file here records one non-obvious technical or product decision: the
context that forced the decision, what was decided, and the trade-offs
accepted. Add a new numbered file rather than editing history — if a
decision is later reversed, add a new ADR that supersedes it and note that
in both files.

| [0003](0003-icloud-sync.md) | CloudKit private database for sync, no custom backend |
